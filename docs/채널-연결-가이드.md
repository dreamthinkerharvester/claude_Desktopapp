# 채널 연결 가이드

설정은 모두 `config.jsonc` 한 파일에서 합니다. 고친 뒤에는 실행기를 다시 켜야 반영됩니다
(`launchd` 로 켰다면 `snspub install-launchd` 를 한 번 더 실행).

연결을 마치면 항상 `snspub check` (또는 화면의 [채널] → [연결 확인])로 확인하고,
**처음에는 채널마다 1건만** 시험 게시해 보세요.

---

## 1. Upload-Post (권장 — 6개 채널을 한 번에)

1. <https://upload-post.com> 가입
   - 무료 플랜: 월 10건, **TikTok 제외** → 시험용
   - Basic: 월 $24 (연간 결제 시 월 $16), 무제한, 프로필 5개 → TikTok 포함 운영용
2. **Profiles** 에서 프로필 하나를 만들고 이름을 `routes.uploadpost.user` 에 적습니다.
3. 그 프로필에 YouTube·Instagram·Facebook(페이지)·TikTok·Threads·X 계정을 연결합니다 (각 SNS 로그인 화면이 뜸).
4. **API Keys** 에서 키를 만들어 `routes.uploadpost.apiKey` 에 적습니다.
5. Facebook 페이지가 여러 개면 `routes.uploadpost.facebookPageId` 에 올릴 페이지 ID.
6. `channels` 에서 6개 채널의 `"route": "uploadpost"` (기본값).
7. `snspub check` → 6개 채널이 ✓ 인지 확인.

참고

- TikTok 공개 범위는 `routes.uploadpost.tiktok.privacy` (기본 `PUBLIC_TO_EVERYONE`). 계정 설정에 따라 허용되지 않는 값이면 첫 게시에서 오류로 알려 줍니다.
- X 글 안의 링크는 Upload-Post 유료 추가 기능이 없으면 지워집니다.
- 한 채널당 요청 1건으로 보냅니다 (채널마다 예약 시각이 달라서).

---

## 2. Meta 직접 연결 (Instagram·Facebook, 무료)

준비: Instagram 계정이 **프로페셔널(비즈니스/크리에이터)** 이고 Facebook 페이지에 연결되어 있어야 합니다.

1. <https://developers.facebook.com> → 내 앱 → 앱 만들기 (비즈니스 유형). **개발 모드 그대로** 두고 본인이 관리자면 앱 검수가 필요 없습니다.
2. 앱 설정 → 기본 설정의 **앱 ID / 앱 시크릿 코드** → `routes.meta.appId`, `appSecret`
3. **Graph API 탐색기**에서 방금 만든 앱을 고르고 권한 추가:
   `pages_show_list`, `pages_read_engagement`, `pages_manage_posts`, `instagram_basic`, `instagram_content_publish`, `business_management`
   → Generate Access Token → 나온 **사용자 토큰** 복사
4. 화면 [채널] → [Meta 토큰 등록] 에 붙여 넣기 (또는 `snspub auth meta --token <토큰>`)
   - 프로그램이 장기 토큰 → **만료 없는 페이지 토큰**으로 바꿔 저장합니다.
   - 페이지가 여러 개면 `routes.meta.pageId` 를 적거나 등록할 때 페이지 ID 를 넣습니다.
5. `config.jsonc`
   ```jsonc
   "instagram": { "enabled": true, "route": "meta", "imagesRoute": "uploadpost" },  // 카드뉴스는 다른 경로
   "facebook":  { "enabled": true, "route": "meta" },
   ```

참고

- Instagram 카드뉴스는 Meta API 가 공개 URL 만 받아 이 경로로는 못 올립니다 → `imagesRoute` 를 `"uploadpost"` 또는 `"manual"` 로.
- Facebook 릴스는 3~90초만 됩니다.
- 비밀번호를 바꾸거나 앱 권한을 지우면 토큰이 무효가 됩니다 → 채널이 "재연결 필요"로 보류되면 4번을 다시 합니다.

## 3. YouTube 직접 연결 (무료, 감사 필요)

> **중요:** Google 의 API 감사(audit)를 통과하지 않은 프로젝트로 올린 영상은 **비공개로 잠겨 나중에 공개로 바꿀 수 없습니다.**
> 그래서 `routes.youtube.audited` 를 `true` 로 바꾸기 전에는 이 프로그램이 올리지 않습니다. 그동안은 `uploadpost` 경로를 쓰세요.

1. <https://console.cloud.google.com> → 프로젝트 만들기 → **YouTube Data API v3** 사용 설정
2. OAuth 동의 화면: 사용자 유형 "외부" → **게시 상태를 "프로덕션 단계"로** 변경
   - "테스트" 상태면 로그인이 **7일마다 만료**됩니다.
   - 본인만 쓰면(100명 미만) "확인되지 않은 앱" 경고가 떠도 그대로 진행하면 됩니다.
3. 사용자 인증 정보 → OAuth 클라이언트 ID → 애플리케이션 유형 **데스크톱 앱** → `routes.youtube.clientId`, `clientSecret`
4. `snspub auth google` → 브라우저에서 로그인·허용 (업로드·읽기 권한)
5. 감사 신청: <https://support.google.com/youtube/contact/yt_api_form>
   (정책상 본인이 공개 범위를 고를 수 있어야 하고, 개인정보처리방침이 있어야 합니다. 기간은 공식 안내 없음)
6. 통과 후 `"audited": true`, 채널 설정 `"youtube": { "enabled": true, "route": "youtube" }`

참고: 하루 업로드 한도는 기본 100건(2026-06 기준, 업로드 전용 한도), 태평양 자정(한국 오후 4~5시)에 초기화됩니다.

## 4. 네이버 카페 (무료)

1. <https://developers.naver.com> → Application → 애플리케이션 등록
   - 사용 API: **카페** (네이버 로그인은 자동 추가)
   - 로그인 오픈 API 서비스 환경: **PC 웹**
   - 서비스 URL: `http://127.0.0.1:4310`
   - Callback URL: `http://127.0.0.1:4310/oauth/naver/callback` (`localhost` 가 아니라 `127.0.0.1`)
   - "개발 중" 상태 그대로 사용 (등록한 본인 계정은 멤버 추가 없이 사용 가능)
2. Client ID / Client Secret → `routes.naver_cafe.clientId`, `clientSecret`
3. 카페에서 올릴 게시판을 클릭했을 때 주소 `https://cafe.naver.com/f-e/cafes/{clubId}/menus/{menuId}` 의 숫자 → `clubId`, `menuId`
4. `snspub auth naver` → 로그인할 때 **"카페" 항목에 동의** (동의하지 않으면 글쓰기가 024 오류)
5. `"public": true` 면 전체 공개 (API 기본값은 멤버 공개)

참고

- 카페 API 는 **영상을 올릴 수 없습니다.** 영상 콘텐츠는 소개글 + 먼저 올라간 채널 주소(`{links}`, 예: 유튜브 쇼츠)로 올라갑니다. 그래서 채널 순서에서 네이버 카페를 맨 뒤에 둡니다.
- 카드뉴스는 이미지 최대 10장까지 첨부합니다. 처음에는 **숨김/테스트 게시판에 1건** 올려 이미지 배치를 확인하고, 이상하면 `"imagePlaceholders": false`.
- 하루 200건 제한. 큰따옴표(`"`)와 이모지는 자동으로 바꾸거나 뺍니다(알려진 오류 회피).

## 5. 네이버 클립 (업로드 도우미)

공개 API 가 없어 `"route": "manual"` 입니다.

1. 예약 시각이 되면 macOS 알림 + 화면에 "직접 올릴 차례"
2. [업로드 도우미] 클릭 → 소개글이 클립보드에 복사되고, 클립 크리에이터(`clipcreators.naver.com`)와 Finder(파일 위치)가 열림
3. 파일을 끌어다 올리고 소개글 붙여 넣기 → 게시
4. [완료] 클릭 (게시 주소를 붙여 넣으면 기록됨)

다른 채널도 `"route": "manual"` 로 두면 같은 방식으로 반자동 처리됩니다 (업로드 페이지는 `routes.manual.urls` 에서 변경).

## 6. 무료로만 쓰는 조합 예

```jsonc
"channels": {
  "youtube":    { "enabled": true, "route": "youtube" },                            // 감사 통과 후
  "instagram":  { "enabled": true, "route": "meta", "imagesRoute": "manual" },
  "facebook":   { "enabled": true, "route": "meta" },
  "tiktok":     { "enabled": true, "route": "manual" },
  "threads":    { "enabled": true, "route": "manual" },
  "x":          { "enabled": true, "route": "manual" },
  "naver_clip": { "enabled": true, "route": "manual" },
  "naver_cafe": { "enabled": true, "route": "naver_cafe" }
}
```

직접 올려야 하는 채널이 4~5개로 늘어나므로, 자동화 비중을 높이려면 TikTok·Threads·X 만 `uploadpost` 로 두는 조합도 가능합니다.
