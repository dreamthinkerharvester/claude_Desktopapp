# 분석: Buffer·참고 프로그램에서 무엇을 가져왔나

조사 기준일 2026-09-27. 공식 문서·공식 SDK·오픈소스 코드를 기준으로 했고, 확인하지 못한 내용은 "(미확인)"으로 표시했습니다.

---

## 1. 실제로 쓰던 기능 (기존 운영 기준)

| 도구 | 쓰던 기능 |
|---|---|
| Buffer 무료 (X·TikTok·Threads 3채널) | 한 번 작성해서 여러 채널에 동시 업로드, 예약 |
| Meta 비즈니스 스위트 | Facebook + Instagram 릴스·카드뉴스 동시 업로드, 예약 |
| YouTube 스튜디오 / 네이버 카페 / 네이버 클립 | 직접 업로드 |

운영 패턴

- 쇼츠 1개를 8개 채널에 **25~40분 간격**으로 예약 (예: 12:50 YouTube → 13:25 Instagram → … → 16:33 네이버 카페)
- 채널마다 톤이 다른 소개글 (Claude Code 세션이 `captions.json` 으로 작성)
- 선택한 채널에 모두 올라가면 원본을 `_업로드완료` 보관 폴더로 이동
- 규모: 월 30건 안팎, Mac mini 한 대

→ 필요한 기능은 **"예약 큐 + 채널별 문구 + 채널별 독립 게시 + 결과 확인 + 보관"** 다섯 가지뿐입니다.

## 2. 프로그램별 분석

### Buffer

- 무료: 3채널, 채널당 동시 예약 10건, API 키 1개·30일 3,000회 호출
- 2026-05-27 모든 요금제에 GraphQL API 공개 (예전 REST API 는 2027-02-01 종료)
- API 로 올릴 때 **미디어는 공개 HTTPS 주소만** 받고(파일 업로드 없음), 채널마다 따로 호출, **멱등 키·웹훅 없음**

| 가져옴 | 안 가져옴 |
|---|---|
| 채널별 예약 큐, 지금 올리기, 예약 수정·취소 | 캘린더 드래그, 게시 시간 추천, 팀·승인 |
| 한 번 작성 → 채널마다 문구 다르게 + 글자 수 표시 | AI 글쓰기 도우미, 링크 단축·Start Page |
| 실패 알림 → 다시 시도, 게시 주소 기록 | 분석 대시보드, 댓글 관리 |

Buffer API 를 게시 경로로 쓰지 않은 이유: 영상을 공개 저장소(R2 등)에 올려 두고 게시가 끝날 때까지 유지해야 하고(관리 부담), 무료는 3채널뿐이며, 멱등 키가 없어 "응답을 못 받은 경우" 중복을 막기 어렵습니다.

### Meta 비즈니스 스위트 (+ Graph API)

- 가져옴: Facebook·Instagram 릴스 게시 → `meta` 경로
  - 개발 모드 앱 + 본인이 관리자면 **앱 검수 불필요**, **만료 없는 페이지 토큰**
  - 로컬 파일을 `rupload.facebook.com` 으로 바로 올림 (공개 저장소 불필요)
- 한계
  - Instagram API 에는 예약 기능이 없음 → 이 프로그램이 예약 시각에 직접 게시
  - Instagram 카드뉴스(이미지)는 **공개 URL 만** 받음 → `imagesRoute` 로 Upload-Post 나 업로드 도우미 사용
  - Facebook 릴스 3~90초, 페이지당 24시간 30개 / Instagram API 게시 24시간 50~100건

### Upload-Post — 보고서 1순위

- `POST /api/upload` (영상), `/api/upload_photos` (카드뉴스)에 **로컬 파일을 그대로** 보냄
- `platform[]` 로 여러 SNS 를 한 번에, 채널별 필드(`youtube_title`, `privacy_level`, `share_to_feed` …)
- 비동기 `request_id` → `/uploadposts/status` 로 결과 확인, `/uploadposts/history` 로 게시 주소
- **`Idempotency-Key` 헤더: 같은 키로 24시간 안에 다시 보내면 원래 작업을 돌려줌 → 중복 게시 방지**
- **YouTube·TikTok 심사를 업체가 이미 통과** → 공개 게시 가능 (TikTok 은 계정마다 허용 공개 범위가 다를 수 있어 첫 1건 확인 권장)
- 요금: 무료 월 10건(TikTok 제외) / Basic 월 $24 (연간 결제 시 월 $16, 무제한, 프로필 5개)
- 주의: X 글의 링크는 유료 추가 기능 없이는 지워짐, TikTok 하루 한도에 걸리면 조용히 '초안'으로 바뀌는 옵션이 있어 이 프로그램은 끔(`disable_inbox_fallback`)

이 프로그램에서 1순위 게시 경로로 구현했고, 채널마다 요청을 따로 보내 25~40분 간격 예약과 채널별 독립 실행을 지킵니다.

### Ayrshare — 보고서 2순위

- 영상 포함 플랜이 월 $149부터, 2026-03-31부터 X 는 본인 개발자 키 필요
- 구조(요청 한 번에 여러 SNS, `idempotencyKey`, 채널별 옵션)만 참고하고 경로로는 구현하지 않음 (필요하면 어댑터 파일 하나로 추가 가능)

### Postiz — 오픈소스 Buffer 대안 (포크 코드 분석)

| 가져온 설계 | 내용 |
|---|---|
| 공급자(provider) 구조 | 채널별 게시 방법을 파일 하나로 분리 → `src/adapters/` |
| 3단계 게시 | 준비(되돌릴 수 있음) → 상태 확인(읽기만) → 확정(되돌릴 수 없음) |
| 오류 분류표 | 토큰 만료 / 입력 오류 / 일시 오류를 코드별로 구분 |
| 결과 불확실 = 실패 아님 | 응답 시간 초과 시 "확인 후 재게시" — 자동 재게시 금지 |
| 재게시 전 플랫폼 확인 | Instagram 컨테이너 PUBLISHED 확인, YouTube 이어올리기 세션 확인 |
| 채널 그룹 독립 | 한 채널 실패가 다른 채널에 영향 없음 |

| 뺀 것 | 이유 |
|---|---|
| Temporal·Redis·Postgres·Prisma | 1인용에 과함 → SQLite 파일 하나 + 15초 주기 확인 |
| 조직·결제·멀티 테넌트 | 혼자 씀 |
| 문자열 부분 일치로 오류 판단, 서버 500 에도 게시 재시도 | 중복 게시 위험 → 코드 번호로 판단, 결과 불확실하면 멈춤 |

### 브라우저 자동화·AI 브라우저 (기존 구조)

보고서와 이전 점검에서 확인된 실패: 계정 불일치(ACCOUNT_MISMATCH), 결과 파일 누락, 매번 과거 게시물 전체 대조, 권한 질문 무한 대기, 실패해도 정상 종료 코드.
→ **전부 제외.** API 가 없는 네이버 클립만 "업로드 도우미"(문구 복사 + 페이지·파일 열기, 사람이 1분 안에 올리고 [완료])로 처리합니다.

## 3. 채널별 공식 게시 통로 (2026-09)

| 채널 | 개인용 직접 API | 이 프로그램의 경로 |
|---|---|---|
| YouTube | 가능. 단 **API 감사 전 업로드는 비공개로 잠김**(공개 전환 불가, 재업로드해야 함). 감사 신청 가능, 기간 공식 안내 없음 | `uploadpost`(권장) · 감사 후 `youtube` |
| Instagram | 가능(개발 모드). 영상은 로컬 파일, 이미지는 공개 URL 필요 | `uploadpost` · `meta`(영상) |
| Facebook 페이지 | 가능(개발 모드, 페이지 토큰 만료 없음) | `uploadpost` · `meta` |
| TikTok | **불가** — 미심사 앱은 비공개(SELF_ONLY)만, "본인·팀 계정 업로드 도구"는 심사 대상 아님 | `uploadpost` · `manual` |
| Threads | 가능하지만 미디어를 공개 URL 로만 받음 | `uploadpost` · `manual` |
| X | 사용량 과금(게시 $0.015, 링크 포함 $0.20), 신규 무료 등급 없음 | `uploadpost` · `manual` |
| 네이버 카페 | 공식 글쓰기 API (글·이미지, 하루 200건). 영상 없음 | `naver_cafe` |
| 네이버 클립 | 공개 API 없음 | `manual` |
| 네이버 블로그 | 글쓰기 API 2020-05-06 종료 | (대상 아님) |

## 4. 최종 기능 목록

1. 수신함 폴더에서 영상 1개 / 카드뉴스 폴더 선택 (파일 해시로 중복 방지, 영상 길이·해상도 자동 확인)
2. 채널별 시각 자동 계산 (순서 + 25~40분 무작위 간격), 채널별 시각·문구 수정
3. 채널별 문구 틀과 해시태그 개수 제한, 글자 수 검사 (X 는 한글 2자 규칙)
4. 예약 시각에 채널별 독립 게시, 처리 상태 확인, 게시 주소 기록
5. 자동 재시도(일시 오류만) / 확인 필요(결과 불확실) / 채널 보류(로그인 문제)
6. 업로드 도우미 (API 없는 채널)
7. 모든 채널 완료 시 원본을 월별 보관 폴더로 이동
8. macOS 알림, 웹 화면, 명령어, JSON 가져오기(Claude Code 문구)
9. launchd 상시 실행, 재시작 시 복구
